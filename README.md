## 🎯 What I Do

### 🤖 Agentic AI & Multi-Agent Systems
- LangGraph orchestration across specialised agents
- Retrieval pipelines — BM25 ∪ vector, RRF fusion, cross-encoder reranking
- Grounded extraction: every field returns a quote, and the code verifies it exists
- Workflow automation with n8n

### 👁️ Computer Vision
- Object detection & pose estimation (YOLO, YOLO-Pose)
- Vision Transformers for medical imaging
- Multi-object tracking with persistent identity (ByteTrack)
- Real-time video analytics behind microservice APIs

### 🗣️ NLP — Arabic & English
- Tashkeel / tatweel removal, Alef–Hamza normalisation, ISRI root extraction
- Text classification, semantic search, embeddings & reranking
- Configurable preprocessing pipelines served over REST

### 📊 Data Science & BI Automation
- End-to-end ML — from raw CSV to a costed business decision
- Held-out evaluation, bootstrap confidence intervals, ablation studies
- LLM-generated dashboards and automated reporting
- SQL data modelling and Power BI

### ⚙️ Deployment & Engineering Practice
- FastAPI services, Dockerised, with enforced domain boundaries in CI
- pytest suites and GitHub Actions across multiple Python versions
- Model registries and single-lifecycle multi-model applications
